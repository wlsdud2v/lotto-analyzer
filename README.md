# 로또 번호 분석기

수집한 추첨 데이터(`data/lotto_draws.json`)로 번호별 확률을 보여 주고 추천 번호를 만들어 주는 웹 프로그램입니다.
서버 없이 `index.html`을 더블클릭하면 바로 열립니다.

## 기능
화면 맨 위에서 **로또 번호 분석기**, **스피또 시뮬레이터**, **운세**를 전환합니다 (바로가기: 주소 끝에 `#speetto`, `#fortune`).

- **이번 회차 1등 예상 총 당첨금** — 메인 상단에 크게 표시. 동행복권 로또6/45 페이지가 발표하는 값(지금까지의 누적 판매액 기준, 판매 마감까지 계속 증가)을 그대로 보여 줌 — 앱은 실시간, 웹은 매시간 갱신. 판매 마감 시 예상 총액(직전 4회 평균 판매액 × 1등 배분율 약 24% + 이월금)과 당첨자 수별 1인당 금액, 판매 마감까지 남은 시간도 함께 표시
- **1등 당첨금** — 역대 최고·최저·최근 평균, 연도별 평균 1인 당첨금 차트, 최근 52회 차트, 전 회차 1등 당첨금·당첨자 수·판매액 표
- **번호 추천** — 균형형 / 핫 넘버 / 콜드 넘버 / 완전 랜덤 4가지 방식
  - **선호 번호**: 번호를 누르면 포함(최대 5개) → 제외 → 해제. 포함 번호는 모든 세트에 들어가고 나머지만 추천
  - 선호 번호와 과거에 함께 자주 나온 번호에 가중치(옵션)
  - 조합 필터: 합계 범위, 홀짝·저고 쏠림, 3연속, 번호대 분산, 역대 1등 조합 제외
  - 이번 주 고정 추천: 같은 설정이면 다음 회차까지 같은 번호가 나옴
  - 각 세트를 과거 전 회차에 대입한 결과, 복사·저장(브라우저에 보관)
- **로또 선생** — 청룡(균형형)·백호(완전 랜덤)·주작(핫 넘버)·현무(콜드 넘버) 선생이 매주 번호를 뽑고 스스로의 운세를 말풍선으로 들려줌 — 지난주 성적, 오랜 공백, 다른 선생 견제·자랑, 행운의 색·방향·물건·시간 팁 등 다양한 대사. 1회부터 모든 회차의 번호를 저장해 선생별 적중률 순위와 지난 기록을 보여 줌 (각 회차 번호는 그 회차 전 데이터만 사용, 선생·회차로 고정된 씨앗이라 누구에게나 같은 번호)
- **타로 추천** — 메이저 아르카나 22장 중 1장(오늘의 카드) 또는 3장(과거·현재·미래)을 골라 카드 해석과 번호 추천. 정방향 카드의 수는 포함, 역방향은 제외, 카드의 기운(핫·콜드·균형·운 + 작은 수/큰 수/홀짝/짝꿍 번호 등)이 가중치가 됨. 같은 주에 같은 카드면 같은 번호
- **물리 추첨기** — 실제 로또와 같은 공기 혼합식 추첨기를 물리 시뮬레이션으로 재현. 45개 공이 바람에 섞이다 배출구로 빨려 올라간 순서대로 6개 + 보너스 추첨 (바람 세기·3배속, 2,400회 시뮬레이션으로 번호별 편향 없음 확인)
- **스피또** — 스피또1000·2000·500 현재 판매 회차의 판매점 입고율(출고율)과 1~3등 잔여·당첨 매수(동행복권 발행내역 데이터, 3시간마다 자동 수집), 긁는 복권 시뮬레이터, 대량 구매·"1등 나올 때까지" 시뮬레이션
- **운세 · 사주팔자** — 성별·양력 생년월일·태어난 시각·지역을 넣으면 사주팔자(년·월·일·시주) 원국, 십신, 오행 분포, 일간 풀이, 신강/신약과 행운의 오행·색·숫자·방향, 대운(순행/역행, 시작 나이) 표시. 절기는 천문 계산(VSOP87)으로 구해 공식 절입 시각과 1분 안팎으로 맞고, 과거 서머타임·UTC+8:30 시기와 지역 경도(태양시)를 자동 보정, 시간 모름·야자시 선택 지원. **오늘의 운세**(오늘 일진과 내 일간의 관계로 총운·재물·대인·건강)와 **이번 주 사주 행운 번호**(행운의 오행 가중치, 주마다 고정). 입력 정보는 기기 안에만 저장
- **번호별 확률** — 출현 횟수/출현률/이론 대비/최근 N회/연속·최장 미출현/보너스/추천 확률 표, 히트맵, 막대 그래프
- **내 번호 확인** — 고른 6개 번호가 과거에 몇 등으로 몇 번 당첨됐을지

## 매주 데이터 갱신 (자동)
- **앱·웹 화면**: 실행할 때 마지막 회차 다음 토요일 21시가 지났으면 인터넷에서 새 회차를 자동으로 받아 추가하고 저장합니다.
  오른쪽 위 **최신 회차 확인** 버튼으로 언제든 직접 확인할 수 있습니다. (출처: github.com/smok95/lotto)
- **PC의 data 폴더**: `tools\update_data.bat` 를 실행하면 `lotto_draws.json / .csv / lotto_data.js` 에 새 회차가 추가됩니다 (Node.js 18 이상 필요).
  `tools\register_weekly_task.bat` 를 한 번 실행하면 Windows 작업 스케줄러에 **매주 일요일 10시** 자동 실행으로 등록됩니다.
  그 시간에 PC가 꺼져 있었으면 다음에 켰을 때 실행되고, 결과는 `tools\update.log` 에 남습니다.
  해제: `schtasks /Delete /TN LottoDataUpdate /F`
- 직접 파일을 고르려면 **데이터 불러오기**로 JSON/CSV 를 선택해도 됩니다.

## 참고
로또는 매 회 독립 시행이라 실제로 각 번호가 뽑힐 확률은 항상 6/45(13.33%), 1등 확률은 조합당 1/8,145,060입니다.
여기서 말하는 "추천 확률"은 과거 패턴으로 가중치를 준 생성기가 그 번호를 고를 확률입니다.

## 안드로이드 앱 (`android/`)
웹 프로그램을 WebView로 감싼 Android Studio 프로젝트입니다 (Java, 외부 라이브러리 없음, Android 8.1 이상).

1. Android Studio에서 **Open** → `D:\web Project\android` 폴더 선택 (처음 열 때 Gradle·SDK 자동 다운로드)
2. 휴대폰을 USB 디버깅으로 연결하고 ▶ **Run** — 또는 **Build > Build App Bundle(s) / APK(s) > Build APK(s)**
   → `android/app/build/outputs/apk/debug/app-debug.apk` 를 휴대폰에 설치

- 빌드할 때마다 상위 폴더의 `index.html, css/, js/, data/lotto_data.js` 가 앱에 자동 복사됩니다.
  웹 쪽만 고치거나 데이터를 갱신(`node tools/build_data.js`)한 뒤 다시 빌드하면 됩니다.
- 앱에서 **데이터 불러오기**로 최신 JSON/CSV를 고르면 앱 안에 저장되어 다음 실행에도 유지됩니다(재빌드 불필요).
- 앱 전용: 추천 번호 **공유** 버튼, 네이티브 클립보드 복사, 시스템 다크 모드 연동.
- **바로 설치용 APK**: `android/release/LottoAnalyzer-2.3.apk` (Gradle 없이 `android/build_apk.sh` 로 빌드, `android/debug.keystore` 로 서명).
  Android Studio 로 빌드한 APK 는 서명 키가 달라서 위 APK 위에 덮어 설치되지 않습니다 — 기존 앱을 지운 뒤 설치하세요.
- Play 스토어 배포용은 **Build > Generate Signed App Bundle / APK** 로 서명 키를 만들어 빌드하세요.
