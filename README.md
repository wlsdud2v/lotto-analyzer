# 로또 번호 분석기

역대 로또 6/45 당첨 번호로 번호별 출현 확률을 보여 주고, 선호 번호를 포함한 추천 번호를 만들어 주는 웹 페이지입니다.

**사이트:** https://wlsdud2v.github.io/lotto-analyzer/

## 기능
화면 맨 위에서 **로또 번호 분석기**와 **스피또 시뮬레이터**를 전환합니다 (스피또 바로가기: 주소 끝에 `#speetto`).

- **이번 회차 1등 예상 총 당첨금** — 메인 상단에 크게 표시. 동행복권 로또6/45 페이지가 발표하는 값(지금까지의 누적 판매액 기준, 판매 마감까지 계속 증가)을 그대로 보여 줌 — 앱은 실시간, 웹은 매시간 갱신. 판매 마감 시 예상 총액(직전 4회 평균 판매액 × 1등 배분율 약 24% + 이월금)과 당첨자 수별 1인당 금액, 판매 마감까지 남은 시간도 함께 표시
- **1등 당첨금** — 역대 최고·최저·최근 평균, 연도별 평균 1인 당첨금 차트, 최근 52회 차트, 전 회차 1등 당첨금·당첨자 수·판매액 표
- **번호 추천** — 균형형 / 핫 넘버 / 콜드 넘버 / 완전 랜덤, 선호 번호 포함·제외, 조합 필터(합계·홀짝·저고·연속 번호), 이번 주 고정 추천
- **로또 선생** — 청룡(균형형)·백호(완전 랜덤)·주작(핫 넘버)·현무(콜드 넘버) 선생이 매주 번호를 뽑고 스스로의 운세를 말풍선으로 들려줌 — 지난주 성적, 오랜 공백, 다른 선생 견제·자랑, 행운의 색·방향·물건·시간 팁 등 다양한 대사. 1회부터 모든 회차의 번호를 저장해 선생별 적중률 순위와 지난 기록을 보여 줌 (각 회차 번호는 그 회차 전 데이터만 사용, 선생·회차로 고정된 씨앗이라 누구에게나 같은 번호)
- **타로 추천** — 메이저 아르카나 22장 중 1장 또는 3장(과거·현재·미래)을 골라 카드 해석과 그 기운에 따른 번호 추천
- **물리 추첨기** — 실제 로또와 같은 공기 혼합식 추첨기를 물리 시뮬레이션으로 재현. 45개 공이 바람에 섞이다 배출구로 빨려 올라간 순서대로 6개 + 보너스 추첨 (바람 세기·3배속, 2,400회 시뮬레이션으로 번호별 편향 없음 확인)
- **스피또** — 스피또1000·2000·500 현재 판매 회차의 판매점 입고율(출고율)과 1~3등 잔여·당첨 매수(동행복권 발행내역 데이터, 3시간마다 자동 수집), 긁는 복권 시뮬레이터, 대량 구매·"1등 나올 때까지" 시뮬레이션
- **번호별 확률** — 출현 횟수·출현률·이론 대비·최근 흐름·미출현 기간 표, 히트맵, 그래프
- **내 번호 확인** — 내 번호를 과거 전 회차에 대입한 당첨 결과

## 데이터 자동 갱신
- GitHub Actions 가 매주 토요일 밤·일요일·월요일에 새 회차를 확인해 `data/` 에 추가하고 사이트를 다시 배포합니다.
- 페이지를 연 사람의 브라우저도 추첨 후에는 최신 회차를 직접 확인해 반영합니다.
- 수동 실행: Actions 탭 → "데이터 갱신 및 배포" → Run workflow
- 데이터 출처: [smok95/lotto](https://github.com/smok95/lotto) (동행복권 결과 기반)

## 직접 실행
`index.html` 을 브라우저로 열면 됩니다. 데이터 갱신은 `node tools/update_data.js` (Node.js 18 이상).

## 참고
로또는 매 회 독립적인 무작위 추첨입니다. 각 번호가 뽑힐 확률은 과거와 무관하게 항상 6/45(13.33%), 1등 확률은 조합당 1/8,145,060입니다.
이 페이지의 통계와 추천은 재미·참고용이며 당첨을 보장하거나 예측하지 않습니다.
